# Notes for AI coding agents (Claude, Codex, etc.)

- **Never commit to `main`** and never push or deploy. Leave your changes in the working tree; the maintainer reviews them and commits.
- Before changing anything under `docs/`, read `README.md`, in particular "What this repository deliberately does NOT contain".
- Do not add external scripts, tracking, links to `web.archive.org`, e-mail addresses or bank details to any page.
- Verify with `mkdocs build --strict` (see `requirements.txt`) before handing back.
