# Call for Papers

## AsiaJCIS 2026 - The 21st Asia Joint Conference on Information Security

AsiaJCIS 2026 invites submissions of original research papers on all aspects of information security. Topics of interest include, but are not limited to:

### Topics

- Access Control
- Applied Cryptography
- Blockchain and Cryptocurrency Security
- Cloud Security
- Cyber-Physical Systems Security
- Data Privacy and Protection
- Digital Forensics
- Hardware Security
- Identity Management
- Intrusion Detection and Prevention
- IoT Security
- Machine Learning for Security
- Malware Analysis
- Network Security
- Privacy-Enhancing Technologies
- Secure Software Development
- Security in AI/ML Systems
- Social Engineering and Phishing
- Trust Management
- Usable Security
- Web Security
- Wireless and Mobile Security

### Submission Guidelines

- Papers must be original and not simultaneously submitted to another journal or conference.
- Paper length: **up to 8 pages** (IEEE format), including references.
- Submissions must be in **PDF format**.
- All submissions will be peer-reviewed.
