Call for Papers

Download the call for papers as a PDF.

The JWIS 2011 solicits original, unpublished research papers on technical and practical aspects of security applications. All articles will be peer-reviewed by at least two independent reviewers. The topics of interest include, but not limited to:
  • Network Security:
    • Internet Security (IPv4, IPv6)
    • NGN Security
    • Home Network Security
    • Mobile/Ad-hoc/Sensor Network Security
    • Networked RFID Security
    • Wireless PAN/LAN/MAN/WAN Security
    • P2P Network Security
    • FW/IDS/IPS
    • DoS/DDoS Attack Countermeasures
  • System Security:
    • System Software/Middleware/OS Security
    • Virtualization Security
    • Database Security
    • Secure eHealth/eBusiness/eCommerce/eGovernment
    • Ubiquitous Security
  • Application Security:
    • Anti-SPAM
    • Web Services Security
    • SNS Security
    • VoIP Security
    • Smart Phone Security
    • IPTV Security
  • Information Security Management:
    • Human Resource Security
    • IT Assurance
    • Security Policy
    • Digital Evidence
  • Cloud Security
  • Smart Grid Security
  • Malware Countermeasures
  • Content Security
  • ID Management and Privacy Controls
  • Biometrics
  • Security Engineering
  • Security Standards
